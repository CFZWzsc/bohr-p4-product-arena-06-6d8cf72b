# Demo task

Turn the synthetic paper in the same directory into section-aligned structured
notes:

- keep the paper's own section order and the links between sections;
- fill a paper card with research question, data, methods and conditions, main
  findings, limitations and conclusions;
- extract searchable knowledge points (concept, variable, method, finding,
  limitation) and merge synonyms/abbreviations;
- give every key note a section + paragraph anchor and a verbatim quote;
- report missing metadata and unmeasured conditions as uncertainties.

This is a synthetic example, not official case output.
